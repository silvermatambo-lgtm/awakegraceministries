# Awake Grace Ministries International – UK

Rebranded from the WebDevPro Ultra Max 5 Master Template for deployment to GitHub and Vercel.

## Included
- Home, About, Ministries, Missions, Children, Events, Gallery, Prayer, Give/Donate and Contact pages
- Ashford and Leicester branch information
- Sunday services and weekly meetings
- Missions and charity sections
- Children’s registration demo form
- Prayer/intercession demo form
- Giving/donation page and giving-intention demo form
- WhatsApp assistant, mobile bottom navigation and PWA install support
- User-supplied church images and event posters
- Vercel SPA fallback configuration

## Important before live launch
The user did not provide verified church banking/payment gateway details or a ministry email address. The donation page therefore intentionally contains a placeholder notice rather than invented bank details. Connect the forms to a secure backend/email/form provider before collecting real submissions.

## Deploy to Vercel
1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
